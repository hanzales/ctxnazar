# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's private vulnerability reporting feature once the repository is hosted. Do not include real secrets, tokens, private keys, or sensitive customer data in a report. Use a minimal fake reproduction.

For ordinary false positives, false negatives, and feature requests that do not expose sensitive data, open a public issue.

## Scanner scope

ctxnazar is a preventive aid, not a security guarantee. It does not verify credentials, inspect Git history, or send scanned content to any service. Rotate a credential immediately if you believe it was exposed.
