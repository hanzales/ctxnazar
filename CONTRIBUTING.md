# Contributing

Thank you for helping improve ctxnazar.

1. Open an issue before substantial changes so scope can be agreed upon.
2. Keep detection deterministic, local-first, and dependency-light.
3. Never add real credentials to fixtures, issues, commits, or pull requests.
4. Add tests for rule changes, including at least one false-positive case.
5. Run `npm run typecheck`, `npm test`, and `npm run build` before submitting a pull request.

Use clear English in source code, comments, documentation, and CLI output. By contributing, you agree that your work is licensed under the MIT License.
